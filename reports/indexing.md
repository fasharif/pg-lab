# Index sizes and write cost

Measured sizes of every index on the TopFlow tables after the casebook fixes, the WAL
each inserted row costs before and after them, and two alternatives that were measured
but not adopted. `docs/indexing.md` explains the choices.

- Generated by `./lab indexing` on 2026-09-25 22:15 UTC.
- Data: SCALE=1000000 (about 1,000,000 order lines), history anchored at 2026-09-25 21:00:00.
- Server: PostgreSQL 18.6 (Debian 18.6-1.pgdg13+2).
- Environment: Docker Desktop (Docker 29.8.0), 16 CPUs and 7.4 GiB of memory for all containers on Windows NT 10.0 build 26200 (Git Bash); pg1 limited to 1g with shared_buffers 256MB; the machine was shared with other parallel builds during this run.
- Timings: pending a measured run. This was a functional run: plans and buffer counts are real, durations were not recorded (see docs/benchmarking.md).
