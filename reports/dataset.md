# Data set

What `./lab seed` generated: exact row counts, the physical order of the time columns
and how the trade orders are spread over the organisations. See docs/data.md for the
model behind these numbers.

- Generated by `./lab seed --scale 1000000` on 2026-09-26 03:34 UTC.
- Data: SCALE=1000000 (about 1,000,000 order lines), history anchored at 2026-09-26 03:00:00.
- Server: PostgreSQL 18.6 (Debian 18.6-1.pgdg13+2).
- Environment: Docker Desktop (Docker 29.8.0), 16 CPUs and 7.4 GiB of memory for all containers on Windows NT 10.0 build 26200 (Git Bash); pg1 limited to 1g with shared_buffers 256MB; the machine was shared with other parallel builds during this run.
- Timings: pending a measured run. This was a functional run: every count, size, plan and check below is measured, but durations were not recorded (see docs/benchmarking.md).
